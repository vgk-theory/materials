# Как участвовать

Спасибо, что помогаете развивать проект. Ниже — правила, которые сохраняют порядок в репозитории при работе многих людей и AI-инструментов.

## Главные правила

1. **Оригиналы неприкосновенны.** Файлы в `sources/` не правятся; можно только добавлять новые оригиналы.
2. **Авторство указывается явно.** Должно быть понятно, что написано автором теории, что создано участниками, а что подготовлено с помощью AI.
3. **Не домысливать.** Положения теории, термины и формулы приводятся только по материалам автора, со ссылкой на источник.
4. **Только относительные ссылки** в html и md (`../shared/style.css`, а не `/animations/shared/style.css`).
5. **Никаких внешних CDN и сборочных инструментов.** Библиотеки, стили и шрифты кладутся в `animations/shared/`.
6. **Видеофайлы и файлы больше 50 МБ** в репозиторий не добавляются без согласования.

## Порядок работы

1. Создайте ветку под задачу: `git switch -c add-transcript-<название>`.
2. Внесите изменения и закоммитьте их с понятным описанием.
3. Отправьте ветку и откройте pull request в `main`.
4. Дождитесь просмотра другим участником; после одобрения изменения сливаются в `main`.

## Именование

- Латиница, строчные буквы, дефисы вместо пробелов: `wave-interaction`.
- Без дат и версий в именах — история хранится в git.
- `index.html` в папке явления всегда означает интерактивную версию.
- Gif носит имя явления: `wave-interaction.gif`; дополнительные версии — с суффиксом: `wave-interaction-side-view.gif`.

## Как добавить анимацию

1. Выберите тему `animations/<topic>/` и, если есть, подтему внутри неё. Новую тему или подтему согласуйте с участниками и положите в её папку `README.md` с названием в первом заголовке.
2. Скопируйте `animations/_template/` в папку темы или подтемы под именем явления: `animations/<topic>/<phenomenon>/`. Для явления в подтеме поправьте в `index.html` пути с `../` — по одному на каждый уровень вложенности.
3. Интерактивную версию оформите в `index.html` и `script.js`; gif положите рядом под именем `<phenomenon>.gif`. Если есть только gif, удалите из папки `index.html` и `script.js`.
4. Заполните `README.md` явления: что показано, источник (глава монографии и/или видео), имеющиеся версии, автор анимации, участие AI. Первый заголовок README становится названием в каталоге.
5. Пересоберите каталог: `python3 animations/build-catalog.py`.
6. Проверьте локально: `python3 -m http.server` в корне репозитория и откройте <http://localhost:8000/animations/index.html>.

Подробнее: [`animations/README.md`](animations/README.md).

## Как добавить транскрипт

1. Добавьте видео в таблицу [`sources/videos/videos.md`](sources/videos/videos.md), если его там ещё нет.
2. Создайте файл `processed/transcripts/<имя>.md` — имя из идентификатора или краткого названия видео.
3. Начните файл с front matter:

   ```yaml
   ---
   source: <ссылка на YouTube>
   source_type: video
   video_url: <ссылка на YouTube>
   video_title: <название видео>
   processed_by: <инструмент/модель или человек>
   processed_date: YYYY-MM-DD
   reviewed_by_human: false
   ---
   ```

4. Отметьте наличие транскрипта в `videos.md`.
5. `reviewed_by_human: true` ставит только человек, сверивший текст с видео.

## Если вы не знакомы с git

Небольшие правки можно делать прямо на сайте GitHub:

1. Войдите в свою учётную запись GitHub и откройте нужный файл в репозитории.
2. Нажмите на значок карандаша («Edit this file») и внесите правку.
3. Нажмите «Commit changes», коротко опишите, что изменили, и выберите «Create a new branch … and start a pull request».
4. Нажмите «Propose changes», затем «Create pull request». Дальше правку просмотрит другой участник.

Новый файл добавляется так же: в нужной папке «Add file» → «Create new file» или «Upload files».

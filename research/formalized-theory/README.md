# Формализованное изложение теории

Систематизированное изложение теории В. Г. Катющика по монографии «Гравитационное взаимодействие, основы космологии»: аксиомы, определения терминов и математический формализм. Это **не текст автора**, а материал последователей, подготовленный с помощью AI: каждое положение снабжено ссылкой на страницу монографии, а всё, что в первоисточнике отсутствует (сводки, реконструкции формул, критические замечания), помечено как позиция составителя.

## Файлы

| Файл | Содержание |
|------|------------|
| [`definitions.md`](definitions.md) | Определения терминов теории с указанием страниц монографии |
| [`axioms.md`](axioms.md) | Постулаты теории о пространстве, времени, силах, массе и гравитации; экспериментальные обоснования автора; отвергаемые им концепции; математическая форма; критический анализ аксиоматики |
| [`formalism.md`](formalism.md) | Математический формализм: поле давления, уравнения поля, ньютоновский предел, размерностный анализ, выявленные пробелы |

Документы читаются в порядке definitions → axioms → formalism: `axioms.md` опирается на термины `definitions.md`, `formalism.md` — на оба.

## Авторство и состояние

- Авторы: участники сообщества; имена в документах не указаны.
- Участие AI: текст составлен моделью Claude (Anthropic) по постраничному тексту монографии.

## Как построены документы и как проходил анализ

**Построение.** Работа шла по постраничному тексту монографии в три шага, каждый следующий опирается на предыдущий:

1. `definitions.md` — выписаны термины с определениями автора и номером страницы; сводки и обозначения составителя помечены отдельно.
2. `axioms.md` — выделены постулаты о пространстве, времени, силах, массе и гравитации, экспериментальные обоснования автора и отвергаемые им концепции; каждому постулату присвоен номер и ссылка на страницу.
3. `formalism.md` — формулы монографии (стр. 30–42) переписаны в LaTeX, записаны уравнение поля и ньютоновский предел, выполнен размерностный анализ, проверены предельные случаи. Формулы, которых в монографии нет, помечены как реконструкция составителя.

**Гейт.** Раздел проходит три последовательные независимые проверки по [`ai/agents/README.md`](../../ai/agents/README.md) и правилам [`ai/scientific-method.md`](../../ai/scientific-method.md): math-verifier → falsifier → peer-reviewer. Единица проверки — раздел целиком (правило 7 гейта): три документа связаны друг с другом (определения → аксиомы → формализм, общие наследуемые стены, один несущий результат), поэтому каждая роль читает все три в одном контексте и пишет один отчёт `reviews/formalized-theory-<роль>-<дата>.md` с хэшами всех файлов; раздельные отчёты по файлам допускаются только для изолированной правки. В [`reviews/`](reviews/README.md) лежат отчёты по текущей редакции документов; отчёты по прежним редакциям после внесения правок переносятся в `reviews/archive/` с пометкой «Устарел» (отчёты до 2026-10-25 были удалены; они доступны только в git).

Постоянного универсального $k_3 = G$ не даёт ни одно из разобранных прочтений формул стр. 35, 39–40 при посылках автора $k_v = k_a = 1$, $f(\alpha) \to 1$; прочтения с дополнительным параметром, которого источник не задаёт ($\sigma$ — вариант (в) §3.1; $f_k$ — анизотропия стр. 41), дают постоянное $k_3$, значение которого источником не определено.

**Кто вносит вердикты.** Отчёты гейта пишут независимые контексты (не автор текста). Статусы VERIFIED / FAILED / INCOMPLETE в `formalism.md` проставлены составителями и проверяются гейтом; материал считается принятым только при вердикте peer-reviewer `ACCEPT` (или `MINOR REVISION` с внесёнными правками). Решение о слиянии в `main` принимает человек.

## Соглашения

- Формулы записаны в LaTeX (`$...$`, `$$...$$`).
- Статусы утверждений в `formalism.md` (единая шкала): VERIFIED — шаг воспроизведён и логически корректен внутри объявленных посылок; FAILED — показано противоречие; INCOMPLETE — данных в первоисточнике или в выводе недостаточно. Статус относится к одному объекту (шагу, формуле); «перенос» и «реконструкция» — пометки провенанса, а не статусы.
- Материалы, не вошедшие в монографию (видеолекции), здесь не отражены.

# OBS-26 — связь смещения спектральных линий галактик с расстоянием до них

| Поле | Значение |
|---|---|
| Что измерялось | Для галактик: относительное смещение длин волн всех спектральных линий (одинаковое для всех линий одного объекта) и расстояние, определённое по светилам известной светимости |
| Установка | Спектрографы; расстояния — по цефеидам и сверхновым типа Ia |
| Результат | Смещение направлено в красную сторону и растёт с расстоянием; на малых расстояниях линейно. Коэффициент, выраженный как скорость на единицу расстояния: около 73 км/с на Мпк по лестнице расстояний; около 67 — из параметров реликтового излучения в рамках космологической модели |
| Допущения обработки | Перевод смещения в скорость — условность записи; второе значение зависит от модели |

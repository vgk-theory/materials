# OBS-27 — растяжение во времени кривых блеска далёких сверхновых

| Поле | Значение |
|---|---|
| Что измерялось | Длительность вспышек сверхновых типа Ia (и скорость изменения их спектров) в зависимости от смещения линий z |
| Установка | (а) кривые блеска 1504 сверхновых обзора DES до z ≈ 1; (б) спектры 13 сверхновых на z от 0,28 до 0,62 |
| Результат | Наблюдаемая длительность пропорциональна (1 + z) в степени b: (а) b = 1,003 ± 0,005 (стат.) ± 0,010 (сист.); (б) b = 0,97 ± 0,10 |
| Допущения обработки | Вспышки одного типа считаются одинаковыми по собственной длительности после поправки на цвет |

Значение факта для темы T-7: вместе со смещением линий во столько же раз растягиваются длительности
процессов в источнике. Значение b = 0 (длительности не меняются) исключено.

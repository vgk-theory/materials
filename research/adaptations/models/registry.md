# Реестр моделей для адаптации

Критерии включения и порядок изменения реестра — [`../README.md`](../README.md), раздел «Реестр моделей».
Состояние записанной модели (счётчик импортов, действующее состояние) — в шапке её `adaptation.md`.
`ADAPTED` означает «адаптирована в скоупе тем, перечисленных в её шапке», а не целиком.
Поле `imports` шапки — число импортов из реестра (`../themes/index.md`), которые модель вводит
собственными утверждениями в этом скоупе, включая общие с другими моделями; следствия агрегата темы в
счёт не входят.

## Описание моделей

### Основная группа

Столбец «чем сильна» — ориентир для выбора тем, а не факты слоя: каждое число, на которое опирается
адаптация, обязано быть записано карточкой `OBS-N`.

### Порядок работы

Рекомендуемый порядок: A-3 (ближе всего к канону: закон силы, масса, равновесие орбит) → A-4 вместе с
A-11 → A-5 → A-10 → A-7 вместе с A-12 → A-6 → A-8 → A-9 → A-13. Модель адаптируется не целиком, а
в скоупе тем: запись модели дополняется разделом на каждую новую тему (как сделано для A-1 и A-2).

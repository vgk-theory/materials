# reviews — отчёты гейта по правкам раздела `corrections`

Отчёты трёх ролей гейта ([`ai/agents/README.md`](../../../ai/agents/README.md)) по каждой
правке. Единица проверки — правка целиком (карточка `PK-<N>.md`, её `sims/` и документы
канона, которые она меняет, в одном контексте): один отчёт на роль,
`PK-<N>-<роль>-<дата>.md` (`math-verification` / `falsification` / `peer-review`), с commit и
sha256 карточки, скриптов и файлов канона.

В корне папки — только отчёты по **текущей** редакции карточки. После правок по отчёту
редакция меняется, гейт проходится заново с math-verifier, а отчёты по прежней редакции
переносятся в `archive/` с первой строкой «> Устарел: редакция <старый hash> заменена
<новый hash>, <дата>. Находки внесены / частично внесены / не внесены (см. новый отчёт)».

Отчёты — рабочие материалы: на сайте не показываются. Статус гейта по каждой правке —
таблица в [`../README.md`](../README.md).

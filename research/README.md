# research — новые исследования

Новые материалы последователей, развивающие теорию. Не смешивать с оригиналами автора ([`../sources/`](../sources/README.md)); в каждом материале явно указывать авторов и участие AI.

## Разделы

| Папка | Содержание | Гейт |
|-------|------------|------|
| [`formalized-theory/`](formalized-theory/README.md) | Формализованное изложение теории по монографии: аксиомы, определения терминов, математический формализм. Подготовлено с помощью AI, человеком не сверено | не пройден: отчётов в `reviews/` нет |

## Обязательные правила раздела

Материалы `research/` — единственное место в репозитории с собственными выводами последователей, поэтому к ним применяются два обязательных документа:

1. **Научный метод и законы логики** — [`ai/scientific-method.md`](../ai/scientific-method.md). Соответствие строгое: каждое утверждение помечено `[ИСТОЧНИК стр. N]`, `[ВЫВЕДЕНО]` или `[ПРОБЕЛ]`; критерии проверки объявляются до расчёта; несущие числа вычисляются из констант с источником; отрицательный результат записывается как результат; законы логики и список запрещённых форм вывода соблюдаются без исключений.
2. **Гейт из трёх ролей** — [`ai/agents/README.md`](../ai/agents/README.md): math-verifier → falsifier → peer-reviewer, в этом порядке, в независимом контексте (не тем, кто писал текст), любой LLM или человеком. Отчёты лежат в `research/<раздел>/reviews/` с хэшем проверенной редакции. Материал считается принятым только при вердикте `ACCEPT` (или `MINOR REVISION` с внесёнными правками); решение о слиянии принимает человек.

Без отчётов гейта материал может лежать в разделе только со статусом «не пройден» в таблице выше. Любое изменение содержания после проверки обнуляет отчёты с первой затронутой роли.

## Как добавить раздел

1. Создайте папку `research/<название>/` (латиница, строчные буквы, дефисы).
2. Положите в неё `README.md`: что это за материал, на какие источники опирается, кто авторы, участвовал ли AI, проверен ли текст человеком.
3. Каждый md-файл начинайте с front matter по образцу [`processed/`](../processed/README.md) (`source`, `source_type`, `processed_by`, `processed_date`, `reviewed_by_human`); положения теории приводите со ссылкой на страницу монографии или видео и с пометками провенанса по [`ai/scientific-method.md`](../ai/scientific-method.md).
4. Проведите гейт: три роли из [`ai/agents/`](../ai/agents/README.md) по очереди, отчёты — в `research/<название>/reviews/`.
5. Добавьте раздел в таблицу выше с текущим статусом гейта и откройте pull request.

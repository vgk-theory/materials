# animations — анимации

Анимации организованы по темам и явлениям, а не по формату:

```
animations/
├── index.html              — каталог анимаций (читает catalog.json)
├── catalog.json            — данные каталога, пересобираются скриптом
├── build-catalog.py        — скрипт пересборки каталога
├── _template/              — шаблон папки явления
├── shared/                 — общие js-библиотеки, стили, шрифты (локально, без CDN)
└── <topic>/                — тема (раздел теории)
    ├── README.md           — название и описание темы
    ├── <subtopic>/         — подтема (если нужна); устроена так же, как тема
    └── <phenomenon>/       — явление
        ├── index.html          — интерактивная версия (если есть)
        ├── script.js
        ├── <phenomenon>.gif    — пассивная версия (если есть)
        ├── preview.gif|png     — только если основной gif тяжёлый
        ├── README.md           — описание явления
        └── src/                — исходники генерации gif (если есть)
```

## Темы и подтемы

- Темы могут быть вложенными на любую глубину: `cosmology/<subtopic>/<phenomenon>/`. Подтему заводят, когда явлений в теме становится много.
- Папка темы содержит `README.md`; его первый заголовок — название темы в каталоге (например, `# Космология`). Имя самой папки — латиницей.
- Папка считается явлением, если в ней есть `index.html` или gif. В папке явления подтем не бывает, а в папке темы не лежат `index.html` и gif.
- При переносе явления на другой уровень вложенности поправьте в его `index.html` относительные пути к `shared/` и к каталогу.

Правила:

- имена: латиница, строчные буквы, дефисы (`wave-interaction`), без дат и версий;
- `index.html` в папке явления всегда означает интерактивную версию;
- gif носит имя явления: `wave-interaction.gif`; дополнительные версии — с суффиксом (`wave-interaction-side-view.gif`);
- явление, у которого есть только gif, тоже оформляется папкой;
- только относительные пути; внешние CDN не подключаются, библиотеки лежат в `shared/`;
- README явления содержит: что показано; ссылку на главу монографии и/или видео; перечень версий; автора анимации; пометку об участии AI. Если автор неизвестен (например, запись взята из публичных источников), так и пишется: «неизвестен».

## Новая анимация

1. Скопируйте `_template/` в `<topic>/<phenomenon>/` и заполните файлы.
2. Пересоберите каталог: `python3 animations/build-catalog.py`. Скрипт обходит темы и подтемы (кроме `_template` и `shared`) и записывает в `catalog.json` те, где есть `index.html` или gif. Название берётся из первого заголовка README явления.
3. Проверьте локально: `python3 -m http.server` в корне репозитория. Каталог читает `catalog.json` через fetch, поэтому открывать страницу как локальный файл нельзя.

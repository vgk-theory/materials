# shared — общие ресурсы анимаций

Общие js-библиотеки, стили и шрифты. Хранятся локально, без внешних CDN, чтобы анимации работали долгие годы. Оформление сайта — `style.css` (цвета и шрифты заданы переменными в начале файла), шрифты — в `fonts/` (Old Standard TT и Golos Text, лицензия SIL OFL), шапка и подвал — `site.js`. В `vendor/` лежат сторонние библиотеки с их лицензиями: marked (разбор Markdown) и KaTeX (формулы) — их использует просмотрщик `view.html`. Подключаются из папок явлений по относительным путям (`../../shared/...`).

# sources — оригиналы автора

Оригинальные материалы автора теории (VGK). Хранятся **без изменений**.

- `monograph/` — труды автора, один файл на труд (`<труд>.pdf`); имя файла задаёт имя папки в `processed/monograph/`. Список трудов — в [`monograph/README.md`](monograph/README.md): он показывается на сайте как страница «Монография», новый труд добавляется в него строкой
- `videos/` — список видео на YouTube (`videos.md`); сами видеофайлы в репозитории не хранятся

Правила:

- существующие файлы не правятся и не «улучшаются»; допускается только добавление новых оригиналов;
- любая обработка (распознавание, перевод в md, транскрипты) лежит в [`../processed/`](../processed/README.md) и ссылается на исходник.
